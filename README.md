# TubeFixLegacy

**LegacyReborn Project** · твик для джейлбрейкнутых iOS 5/6 (armv7/armv7s)

TubeFixLegacy возвращает к жизни старые YouTube-клиенты:

| Приложение | Версии | Как работает |
|---|---|---|
| YouTube от Google (App Store) | 1.0.0, 1.0.1, 1.1.0, 1.2.1, 1.3.0, 1.4.0, 2.0.0, 2.1.x, 2.2.x | собственный клиент InnerTube (из TubeReplacer), со входом в аккаунт |
| YouTube Classic (пакеты «Classic YouTube App» для iOS 6, `com.apple.youtube`) | 1.0.0 | перенаправление на TubeRepair-совместимый сервер |
| YouTube от Google других версий | любые | то же перенаправление, что и для Classic |

Основан на [TubeReplacer](https://github.com/Preloading/TubeReplacer) от Preloading (GNU GPL v3). Иконка из [TubeRepair](https://github.com/bag-xml/TubeRepair) (bag.xml).

**Установка**: Cydia-репозиторий LegacyReborn — `http://repo.legacyreborn.cfd/` (пакет `com.legacyreborn.tubefixlegacy`), или `.deb` со [страницы релизов](https://github.com/LR-Vensuki/TubeFixLegacy/releases).

## Что умеет

- **Шортсы**: пункт «Shorts» в боковом меню (лента шортсов, прокрутка догружает новые), шортсы внутри обычных лент показываются обычными строками.
- **Шортс-плеер**: тап по шортсу открывает полноэкранный вертикальный плеер — свайп вверх/вниз листает шортсы (сначала из той же ленты, дальше — рекомендации YouTube Shorts от выбранного ролика через `reel_watch_sequence`, персональные, если вы вошли; при тапе из пункта «Shorts» бокового меню рекомендации идут сразу после выбранного ролика), видео зацикливается, тап — пауза, двойной тап — лайк. Справа лайк/дизлайк со счётчиками (Return YouTube Dislike), «Поделиться» и «Плеер» (открыть шортс в обычном плеере приложения с комментариями). Лайки ставятся от вашего аккаунта, если вы вошли. Потоки берутся так же, как в обычном плеере, поэтому настройка «Поток» действует и здесь. Отключается переключателем «Шортс-плеер».
- **Фоновое воспроизведение**: звук видео продолжает играть при блокировке и сворачивании. На 1.0.x и 1.1.0 iOS даёт максимум ~10 минут (у этих версий нет фонового аудио-режима в Info.plist). Сворачивать нужно, когда видео уже заиграло: если уйти из приложения во время загрузки, iOS усыпляет его и загрузка прерывается.
- **Экран блокировки / панель многозадачности**: название, автор, обложка, прогресс; кнопки play/pause и перемотка ±N секунд; кнопки гарнитуры.
- **Щипок «во весь экран»**: в полноэкранном режиме развести два пальца — видео обрезается до заполнения экрана без чёрных полос, свести — снова видно целиком. При выходе из полноэкранного режима всё возвращается. Переключатель «Щипок — во весь экран».
- **Перемотка двойным тапом**: левая/правая половина плеера, повторные двойные тапы суммируются (10 → 20 → 30 с). Шаг настраивается.
- **YouTube Classic**: ленты, поиск, похожие видео и воспроизведение через сервер TubeRepair (по умолчанию `http://tuberepair.uptimetrackers.com`), фон и пульт с названием видео. Вход устройства (applelogin) пропускается: на телефонах без сертификата устройства (активация в обход и т.п.) из-за него Classic писал «Не удалось подключиться к YouTube».
- **YouTube 2.1.x и 2.2.x**: работают через те же пути, что и 2.0.0 (включая вход в аккаунт). Эти версии не сверялись с бинарниками, поэтому, если в них изменился какой-то инициализатор моделей (YTVideo, YTChannel и т.п.), твик не падает, а перенаправляет вызов на ближайший существующий и пишет об этом в системный журнал (`[TubeFixLegacy] YouTube 2.x.x: … has no …`).
- **Медленный интернет / VPN**: запросы к YouTube ждут ответа 30 секунд вместо 8, иначе через VPN приложение часто показывало «Ошибка при загрузке».

Настройки: «Настройки» → «TubeFixLegacy» (на русском и английском; пункт «Язык» — «Автоматически» по языку iOS, English или Русский — переключает и настройки, и тексты твика в YouTube). На главной странице только основное: шортсы, фон, экран блокировки, двойной тап и шаг перемотки, сервер для Classic и кнопка «Перезапустить YouTube». Качество видео, категории и редкие опции — в подразделах «Качество видео», «Категории» и «Дополнительно». Настройки TubeReplacer переносятся автоматически при первом запуске.

Совет: «Качество видео» → «Поток» → **HQ (web)** запускает видео заметно быстрее, чем «360p (Android)» (на iPhone 4S через VPN: ~10–25 с против 35–50 с).

## Сборка в Xcode 4.6.3 (OS X 10.8)

1. Откройте `TubeFixLegacy.xcodeproj`.
2. Схема **TubeFixLegacy**, устройство **iOS Device**.
3. **Product → Build** (⌘B).
4. Готовый пакет: `packages/com.legacyreborn.tubefixlegacy_<версия>_iphoneos-arm.deb`.

Цель проекта запускает `xcode/build.sh`: Logos → clang (armv7 + armv7s, iPhoneOS 6.1 SDK, iOS 5.0+) → lipo → ad-hoc подпись `codesign` → сборка .deb (`xcode/mkdeb.py`, dpkg не нужен). Лог сборки — в Report Navigator (⌘7).

То же из Терминала: `bash xcode/build.sh` (очистка: `bash xcode/build.sh clean`).

После добавления/удаления файлов или правки `.x`:

```
python xcode/regenerate.py    # списки исходников + заранее сгенерированный вывод Logos
python xcode/genproject.py    # пересоздать TubeFixLegacy.xcodeproj
```

`xcode/generated/` используется, только если Perl/Logos на машине не запускается.

## Сборка через Theos

```
make package FINALPACKAGE=1
```

Makefile настроены на `iphone:clang:6.1:5.0` и `armv7 armv7s` — тот же SDK, что в Xcode 4.6.3.

## Диагностика

- Включите «Дополнительно» → «Подробный журнал» в настройках твика: в системный журнал пишутся запросы с ошибками, запуск/пауза видео, двойной тап, уход в фон, кнопки пульта.
- Подключите iPhone по USB и выполните `python3 tools/idev.py syslog 120 | grep TubeFixLegacy` (нужна только пара с компьютером, как у iTunes/3uTools).
- Отчёты кнопки «Отправить отзыв» в приложении сохраняются в `/var/mobile/Library/Logs/TubeFixLegacy/`.

Для разработки по USB, без SSH:

- `bash tools/deploy.sh` — копирует собранное (`make stage`, папка `.theos/_`) на телефон через AFC2 (пакет «Apple File Conduit "2"»), после чего достаточно перезапустить YouTube.
- `python3 tools/vncd.py serve` — держит VNC-сессию с Veency (пароль спрашивается в терминале); `python3 tools/vncd.py shot out.png`, `tap X Y`, `dtap X Y`, `swipe ...`, `home` управляют телефоном из скриптов. Во время воспроизведения видео Veency показывает чёрный экран — это ограничение захвата, а не ошибка.

## Структура

- `googleapp/` — твик для YouTube от Google (`TubeFixLegacy.dylib`): `playback.x` (фон, экран блокировки, пульт), `doubletapseek.x`, `categories.x`/`frontfeed.x`/`TRShorts.m` (шортсы), `TRShortsPlayer.m`/`shortsplayer.x` (шортс-плеер), `pinchfill.x` (щипок «во весь экран»), `TRSelectorCompat.m` (страховка для 2.1/2.2) и код TubeReplacer.
- `classic/` — YouTube Classic и неподдерживаемые версии (`TubeFixLegacyClassic.dylib`).
- `preferences/` — панель настроек.
- `common/`, `common-google/`, `lib/` — клиент InnerTube, SABR, protobuf.
- `xcode/` — сборка для Xcode 4.6.3.
- `depiction/` — описание пакета для Cydia-репозитория.
